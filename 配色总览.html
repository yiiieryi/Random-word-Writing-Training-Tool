词雾 · 配色总览

共 3 类：全局色板（改 tailwind.config.js 全局生效）· CSS 组件类 · 硬编码颜色（需逐文件改）

2. CSS 组件类 index.css

基于全局色板的组件样式类，改色板后自动同步。btn-danger 是唯一硬编码色的组件类。

.btn-primary
bg-accent → hover:bg-accent-deep
主按钮：保存、重新随机、创建、导出
.btn-danger
#b0523a → hover:#8f3f2c 硬编码
危险按钮：删除确认
.btn-soft
bg-accent-soft → hover:bg-accent/15
软按钮：开始写作、查看全部、取消操作
.btn-ghost
text-ink → hover:bg-accent/8
幽灵按钮：取消、导出、导入、导航
.field
bg-card border-line → focus:border-accent/40
输入框：标题、分类名、词汇、导入文本
遮罩 / 选区 / 滚动条
遮罩 bg-ink/25 · 选区 rgba(60,60,56,0.15) · 滚动条 #c8c6c0
弹窗遮罩、文本选中、滚动条

3. 硬编码颜色 需逐文件修改

这些颜色没有走全局色板，修改时需要直接改对应文件中的值。

Logo 主圆 · 红棕 Logo.tsx
#b0523a — 与 btn-danger 同色，logo 左侧大圆
Logo 次圆 · 深绿 Logo.tsx
#3f5a4b opacity 0.88 — logo 右上小圆
Logo 底圆 · 浅米 Logo.tsx
#d9c6a8 — logo 底部小圆
Toast info 图标 · 暖金 useToast.tsx
#c9b48a — info 类型 toast 的图标色（成功用 pine，错误用 accent）
词汇标签 / 代码块背景 · 白70% WordLibrary.tsx
bg-white/70 — 词库页词汇胶囊标签、导入面板代码示范块背景（共 3 处）
导出计数徽章 · 白20% Settings.tsx
bg-white/20 — 设置页导出按钮上的文稿数量小徽章

4. 首页 Canvas 专属配色 Landing.tsx

首页词雾动效的 Canvas 绘制颜色，独立于全局色板。

Canvas 背景
#f1f1ee（与 paper 一致）
首页全屏底色
文稿短语文字
rgba(35, 35, 35, alpha)
首页展示的已保存文稿短语，明度随粒子状态变化
词库词文字
rgba(35, 35, 35, alpha × 0.55)
词库单词，比文稿短语更淡（0.55 倍明度）
鼠标光晕
rgba(255,155,84,0.18) → rgba(255,208,127,0)
半径 40px，multiply 混合，暖橘橙中心→熔金透明边缘
鼠标拖尾
[255,155,84] → [255,184,102] → [255,208,127]
3 色暖橙渐变，最大不透明度 0.14，鼠标移动时产生

修改建议： 全局风格调整只需改 tailwind.config.js 中的 9 个 token； Logo 三色、Toast info 色、WordLibrary 的 white/70、首页 Canvas 文字/光晕/拖尾需单独改对应文件。 检查后告诉我要改哪些，我直接修改。
